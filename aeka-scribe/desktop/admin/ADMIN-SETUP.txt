FLOW DESKTOP 0.3 — ADMINISTRATOR AND PUBLISHER SETUP

DEVICE POLICY
Deploy policy.example.json as %ProgramData%\Flow Desktop\policy.json, with ACLs
that permit ordinary users to read it and only administrators to modify it.
Restart Flow after policy changes. Invalid policy files prevent startup.

All boolean fields default to true. retentionDays supports 0 (no maximum),
7, 30, 90 or 365 days since the note's last update. The shorter managed/user
period wins. Active recordings and pending audio are protected. Retention runs
while Flow is open. Exports are app controls, not a DLP or anti-copy guarantee.
This release does not provide SSO, SCIM, MDM enrollment or certification.

SIGNED UPDATE FEED
The automatic updater is implemented but no production publisher/feed is
provisioned. The delivered development packages are unsigned. Do not disable
signature validation to distribute them through the updater.

1. Build an NSIS installer from the saved source and sign the executable and
   installer with your organization's trusted Windows code-signing certificate.
2. Maintain an Ed25519 release-manifest signing key in your secret manager.
   The app receives only the public PEM key and Windows publisher thumbprint.
3. Run desktop/scripts/sign-release.mjs from the source checkout with the
   private-key file path in FLOW_UPDATE_SIGNING_KEY_FILE. The helper writes a
   signed JSON manifest. It never embeds or prints the private key.
4. Publish the manifest and installer at HTTPS URLs on the same origin.
   Keep the expiry within 31 days (the helper uses 14). No redirects are used.
5. In Desktop settings > Publisher setup, configure the trusted feed URL,
   Ed25519 public key and 40-character Windows certificate thumbprint.
   Automatic checks/downloads are optional and run every six hours while open.
6. The client checks product, platform, version, expiry, byte count, SHA-256,
   Ed25519 signature and Windows Authenticode publisher. Installation requires
   an explicit click and is blocked during recording or pending transcription.

No service credentials or signing material are included in the source or
package. This updater does not use the ChatGPT private-site bypass credential.
