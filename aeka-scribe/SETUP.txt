SECURITY / CONFIGURATION
Native credentials and audio use the DPAPI-backed encrypted vault. The first
sync account is pinned; another account cannot import or receive its data.
Hosted sign-in runs in a separate sandboxed Electron session without a preload
or Node access. Fixed same-site session.fetch requests use normal authenticated
cookies; no platform bypass token, copied browser credential or forged identity.
Disconnect clears this isolated web session but keeps both stores' existing notes.
Sync excludes raw audio, API keys, calendar tokens and dictation profile/history.
Grants do not change platform audience. The same owner-private Site remains private.
Hosted APIs enforce identity, same origin, ownership/role, revisions and policies.
All schema changes are generated D1 migrations; deployed migrations are immutable.

Native calendar OAuth still needs the user's Google/Microsoft client registrations.
Hosted calendar eligibility tooling is absent, so no unsupported connector binding
or event snapshot was created. Google Calendar is connected to ChatGPT separately.
OpenAI key: native user enters it in Desktop settings. Hosted OPENAI_API_KEY remains
unconfigured; provision only through the approved OpenAI Developers / Sites flow.
Local ASR requires a trusted whisper-cli.exe and ggml model chosen in native dialogs.

UPDATES / ADMINISTRATION
Only administrator-protected policy.json at %ProgramData%\Flow Desktop is loaded.
Invalid policy fails closed. Exports are app controls, not a DLP guarantee.
A publisher must provide an HTTPS feed, Ed25519 release key and trusted Windows
code-signing certificate. The client validates expiry/product/platform/version,
file size/hash, signed manifest and Authenticode certificate. No certificate or
feed is fabricated. The delivered ZIP/NSIS builds are unsigned development builds.

LIMITATIONS STILL REQUIRING EXTERNAL SETUP OR VERIFICATION
Real Windows startup, microphone/loopback, cursor insertion, power events,
OAuth consent, embedded hosted sign-in/session cookies, real model accuracy and
installer/update execution need Windows testing. No provider chargeable AI call
or live calendar/sharing action was performed. No code signing/feed, bundled
Whisper binary/model, SSO/SCIM/MDM, Slack connector or vendor Voice
Profile model is provisioned. Speaker identities are local to each audio chunk.
Current unfinished audio can still be lost on forced termination. Continuous sync
runs only while Flow is open, up to 25 changes per 15-second pass; hosted polling
runs on visible notes pages. Notes are explicitly saved. No meeting bot or call
login bypass exists. App-level audit is not a compliance certification.

Browser dictation reliability (2026-10-19):
The previous continuous-mode handler joined every result entry. Replaying a
provider list of cumulative hypotheses reproduced the reported growing-prefix
repetition. That replay establishes a failure path, not a capture of the user's
actual browser events. Browser dictation now uses single-utterance recognizers:
each live hypothesis replaces the current turn, and each turn commits at most
once. Natural utterance completion starts the next recognizer until Finish,
Cancel, silence, an error, or the existing five-minute session limit. There can
be a short listening gap between browser utterances; cloud recording remains
the continuous-audio option. No text-based deduplication is applied, so spoken
repetitions and identical consecutive sentences remain intact. There is no
new transcript logging, data migration, provider, or credential requirement.
Regression tests drive the production browser controller with cumulative and
indexed hypotheses, corrections, repeated sentences, stop/cancel races, stale
callbacks, microphone denial, network errors, and finish timeouts. These are
simulated speech events, not a hardware/Windows microphone accuracy benchmark.
The real React page/hook was also checked in the managed browser using a
temporary recognizer fixture: the reported phrase saved once, two intentionally
identical utterances were retained, and cancelled/late events added no history.
The fixture route was removed before the production build.
